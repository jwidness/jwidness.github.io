iNaturalist Common Ancestor

Find the finest common ancestor of iNaturalist taxa — the node you'd use as a coarse ID when an observation has multiple possibilities. Or enter a single taxon to use as a plain tree browser.

Try: Cooper's Hawk + Sharp-shinned Hawk.

How to use

Add taxa by name or ID number — the tree rebuilds as you go. Add two or more and the node that contains all of them is badged as the finest common ancestor. Each taxon links to its iNaturalist page, and hovering a taxon shows photos and the Wikipedia description (click a photo to open it on iNaturalist).

  • ▸ arrow — expand or collapse a node. Ctrl-click (⌘-click on Mac) to expand or collapse all sibling nodes too (expanding skips siblings whose children haven't been loaded yet).
  • show all children — on a node along the path, pull in its other children so you can browse past the target lineage; hide extra children removes them again.
  • Hide minor ranks — collapse the path down to the seven major ranks (kingdom → species), hiding subgenus, tribe, etc. Choosing show all children turns this off, since that's a request for the full structure.
  • Collapse all closes every node but keeps what's loaded; Reset tree returns to the plain common-ancestor view.
